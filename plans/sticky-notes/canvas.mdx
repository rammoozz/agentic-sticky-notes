<Annotation targetId="wide" placement="right" title="Claude pins as it works">
- A note shows in the pane right after `note_add` runs. The tool rows in the chat look like any other MCP call.
- **This chat** holds notes that only matter in this talk. **Project** holds notes every session in this repo should see. Claude picks per note.
- Color = kind: needs you, todo, decision, remember. A needs-you note also sends a terminal notification.
- Wide terminal: pane sits beside the chat. Narrow: Claude Code puts it above the prompt. `/notes` shows or hides it.
</Annotation>
